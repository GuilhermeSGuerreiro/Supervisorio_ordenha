# Planilhas

| Arquivo | Uso |
|---|---|
| `bom.csv` | Lista de componentes com faixas de preço. Totais por `tools/bom_totais.py` |
| `custos.csv` | Toda compra, com nota fiscal quando houver |
| `horas.csv` | Horas trabalhadas por etapa. Entram no custo do produto |
| `validacao_balanca.csv` | Comparações das fases 1, 2 e 3 de `docs/04-validacao.md` |
| `tempos.csv` | Cronometragem das sessões sem e com o sistema |
| `revisao_semanal.csv` | Revisão semanal com o operador |

Na planilha de validação, `meta_g` é o maior valor entre 200 g e 2% da massa transferida, e `erro_g` segue a fórmula de `docs/04-validacao.md`.
